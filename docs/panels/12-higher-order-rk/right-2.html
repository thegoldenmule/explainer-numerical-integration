Implicit Euler

The same one step, but solved for the next state instead of the current one:

xi+1=xi+h·f(ti+1,xi+1)

The unknown appears on both sides, so each step is an equation to solve, and for a general force that means a root-finding loop inside every frame. That is why it turns out to be really hard to implement. For a linear system it is cheap: the step is a fixed 2×2 matrix, inverted once.

Apply it to the modal equation and the root is z=1/(1−hλ), so the region is

|1−hλ|≥1

the outside of a disk of radius 1/h centered at +1/h: stable almost everywhere, including the entire left half plane, at any step.

The catch is in the number, not the region. For the current spring |z|=0.947 per step where the exact factor is 0.9983, so the method drains energy the spring should keep. With the essay’s parameters it reads 0.26 at t=60 against an exact 0.71. The larger the step, the heavier the damping. Never explodes, always lies.

Drag h=0.033 through the bundle of implicit runs to highlight one and watch the over-damping grow with the step.
