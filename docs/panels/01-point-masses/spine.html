Point masses

There are loads of physics engines out there that you may not realize are physics engines. Particle systems are some of the simplest, as they treat each physical object as a dimension-less point.

This is called a point mass or more generally, a body.

Its entire state is a position and a number,

(x,y) = (1.00,0.50) , m=1.00

From here, we need to describe how the body is affected and how it moves in space.
