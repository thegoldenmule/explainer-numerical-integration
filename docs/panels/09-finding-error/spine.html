Finding error

To find this optimal time step, LST relies on error calculation. Intuitively speaking, LST is looking for a threshold where our simulation has accumulated “too much error”, in which case it kerplodes.

The main idea of this type of analysis is that we want to calculate the ratio of future to present error, usually denoted by z. If we can explicitly calculate this ratio, then we know whether error is growing or shrinking. This means that what we’re going to be looking to do is pick parameters of our system and our numerical methods such that this ratio is less than one. If we can do that, then we’ve proved that our error is shrinking.

Here the ratio is measured, not derived: the error at step i+1 divided by the error at step i, and from it the time the error takes to double, h·ln2/lnz.

Before any method can be analyzed, the system has to be reduced to one number: the modal equation, to the right, does that, and panel 10 is built on it. Read it before going on.
