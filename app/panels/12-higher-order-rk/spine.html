Higher-order Runge-Kutta

If we try the same spring simulation on a higher order Runge-Kutta numerical method, like the fourth order (abbreviated RK4), it runs without issue. The first two terms of RK4 are equivalent to Euler’s method; working the analysis through, it’s common to define a function q such that

q(hλ)=1+hλ +(hλ)22 +(hλ)36 +(hλ)424

so that the characteristic polynomial is p(z)=z−q(hλ), with a single root at z=q(hλ). RK4 is numerically stable when |q(hλ)|≤1. Not only is the stability region pretty dang large for a stupidly big step size, the RK4 method handles oscillation much better as well.

For completeness, the implicit Euler method’s region is |1−hλ|≥1: the outside of a disk, stable almost everywhere. Careful readers will ask: why not use this for everything? It turns out to be really hard to implement, and it has a cost the region does not show: it never explodes, but its spring is visibly over-damped against the exact curve.
